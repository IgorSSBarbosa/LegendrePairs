# Legendre-pair census + GG-orbit structure (`census.py`)

Exact enumeration of Legendre pairs (LPs) for odd lengths $\ell$, organized by
the orbits of the "good group" $GG$. It answers two questions per $\ell$: **how
many pairs are there**, and **into how many $GG$-classes do they fall** (so you
know when a single seed's orbit is or isn't the whole solution set).

## Baked-in facts (stated here, not re-derived at runtime)

**Legendre pair (normalized).** $u, v \in \{-1,+1\}^\ell$, $\ell$ odd, each with
exactly $(\ell-1)/2$ entries $=-1$ (so $\mathbf 1^\top u = \mathbf 1^\top v = +1$),
satisfying

$$\mathrm{PAF}(u,j) + \mathrm{PAF}(v,j) = -2 \quad\text{for all } j \neq 0 \pmod \ell,$$

where $\mathrm{PAF}(w,j) = \sum_i w_i\, w_{(i-j)\bmod\ell}$.

**Signature form (necessary AND sufficient).** With
$\sigma(u) = (\mathrm{PAF}(u,1),\dots,\mathrm{PAF}(u,(\ell-1)/2))$ (integer valued,
and $\mathrm{PAF}(u,j)=\mathrm{PAF}(u,\ell-j)$ so the first half determines it),

$$(u,v)\text{ is an LP} \iff \sigma(v) = (-2,\dots,-2) - \sigma(u).$$

So the pair count is a convolution of the signature histogram with its
complement — no need to test $M^2$ pairs.

**The good group $GG$.** $|GG| = 4\,\ell^2\,\varphi(\ell)$. $GG$ acts by
**coordinate permutations** (hence preserves the normalization), generated by

| generator | action on the pair | as a position permutation |
|---|---|---|
| `shift_u` | $(c_1 u,\, v)$, $\;c_1(w)_i = w_{i-1}$ | $p \mapsto p+1$ on $u$ |
| `shift_v` | $(u,\, c_1 v)$ | $p \mapsto p+1$ on $v$ |
| `decim` | $(d_g u,\, d_g v)$, $\;d_k(w)_i = w_{i k^{-1}}$ | $p \mapsto p\cdot k$ on both |
| `reverse_v` | $(u,\, d_{-1} v)$ | $p \mapsto -p$ on $v$ |
| `switch` | $(v,\, u)$ | swap members |

(For decimation the code applies **every** unit $k \in \mathbb Z_\ell^\times$, so it
works even when $\mathbb Z_\ell^\times$ is non-cyclic, e.g. $\ell=15$.)

**Ground truth is enumeration.** $M = \binom{\ell}{(\ell-1)/2} \le 92378$ for
$\ell \le 19$, so we count exactly. $GG$ is used only to *organize and validate*.
A single seed's orbit equals the whole LP set **only when there is one class**
($N=1$). The code never claims otherwise — it prints a caveat when $N>1$.

## Results ($\ell = 5\ldots19$)

Written to `census.csv`. `T_ordered` = ordered LP pairs, `T_unordered` =
different pairs (switch is in $GG$), `T_diag` = self-paired ($u=v$) LPs,
`N_classes` = number of $GG$-orbits.

| $\ell$ | $M$ | $\lvert GG\rvert$ | T_ordered | **T_unordered** | T_diag | N_classes | orbit sizes |
|---|---|---|---|---|---|---|---|
| 5  | 10    | 400   | 50     | 25    | 0  | 1 | 50 |
| 7  | 35    | 1176  | 196    | 105   | 14 | 1 | 196 |
| 9  | 126   | 1944  | 972    | 486   | 0  | 1 | 972 |
| 11 | 462   | 4840  | 2904   | 1463  | 22 | 2 | 484, 2420 |
| 13 | 1716  | 8112  | 7098   | 3549  | 0  | 4 | 338, 1352, 1352, 4056 |
| 15 | 6435  | 7200  | 38700  | 19365 | 30 | 8 | 900, 1800, 3600×2, 7200×4 |
| 17 | 24310 | 18496 | 93058  | 46529 | 0  | 7 | 578, 9248×2, 18496×4 |
| 19 | 92378 | 25992 | 161728 | 80883 | 38 | 9 | 1444, 8664×2, 12996, 25992×5 |

Every orbit size divides $|GG|$ and equals $|GG|/|\mathrm{Stab}|$ (asserted).
Only $\ell = 5, 7, 9$ have a single class — for $\ell \ge 11$ a single seed is
**incomplete** and the run says so.

## Usage

```bash
python3 census.py --step 1 --lmin 5 --lmax 19          # |GG| table
python3 census.py --step 2 --lmin 5 --lmax 19 --orbits # census + orbit partition
python3 census.py --step 2 --lmin 5 --lmax 19          # counts only (skip orbits)
python3 census.py --step 2 --lmax 19 --cores 4         # parallel signature census
python3 census.py --greedy                             # Step 3 stub -> NotImplementedError
```

Flags: `--lmin/--lmax` (even $\ell$ are skipped, $T=0$), `--cores` (worker
processes for the signature census), `--orbits` (opt-in orbit partition),
`--greedy` (registered stub), `--quiet`.

## Outputs

- `census.csv` — one appended row per completed $\ell$ (columns above). On
  interruption only *completed* $\ell$ are present — no fabricated counts.
- `seeds/ell{ℓ}.json` — one representative pair per $GG$-class (bitmasks).
- `ckpt/ell{ℓ}.pkl` — atomic, resumable checkpoint of the signature census,
  written every 50 000 combinations; a run can be stopped and restarted anytime.
- `cost.csv` — header only; populated by the Step 3 greedy search once
  implemented.

Bitmask convention: a sequence is encoded by the integer whose set bits mark the
positions equal to $-1$.

## Step 3 (`--greedy`) — not implemented

Registered as a documented placeholder that raises `NotImplementedError`.
Intended design: hill-climb on the fitness
$F(u,v) = \sum_j (\mathrm{PAF}_u(j)+\mathrm{PAF}_v(j)+2)^2$ (zero iff LP) via
single-coordinate sign flips with many random restarts; record the empirical
per-restart success rate $q$ and estimate restarts-to-first-success as
$N_\delta \approx \log(\delta)/\log(1-q)$. Emits `ell, restarts, successes,
q_empirical, N_delta_est` to `cost.csv`.

## Tests

`../tests/test_census.py` (runs standalone or under pytest): Parseval
$\sum_k|\hat u(k)|^2=\ell^2$, PAF symmetry, census == brute force over all $M^2$
pairs for $\ell\in\{5,7,9\}$, $\sum(\text{orbit sizes})=$ `T_ordered`,
$|\mathrm{Stab}_i|\cdot\text{orbit}_i=|GG|$, `seed_expand(rep)` == its union-find
orbit for every class, and single-class completeness.
